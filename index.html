เครื่องมือสนับสนุน TRACE–TRUST สำหรับการทดลองเชิงโครงการ
โครงการ: แนวทางการพัฒนาระบบการร้องเรียนในสถานพยาบาลภาครัฐขนาดใหญ่ในเขตพื้นที่บางกอกน้อย กรุงเทพมหานคร

Prototype นี้รองรับทั้ง บุคคลภายในสถานพยาบาล และ บุคคลภายนอก เช่น ผู้ป่วย ผู้รับบริการ ญาติ/ผู้ดูแล ประชาชน ผู้มาติดต่อ คู่ค้า ผู้รับจ้าง และหน่วยงานภายนอก เพื่อให้เสียงสะท้อนของผู้มีส่วนได้ส่วนเสียเข้าสู่กระบวนการเดียวกัน

TRACE Model • “เรื่องเดินอย่างเป็นระบบ”

ใช้แนวคิด NPM สนับสนุนการจัดการด้านระบบ ตั้งแต่รับเรื่อง ประเมิน ส่งต่อ กำหนดเจ้าภาพ ตรวจสอบ แก้ไข ไปจนถึงนำข้อมูลกลับไปพัฒนา

TRUST Model • “คนเชื่อมั่นในกระบวนการ”

ใช้แนวคิด PVM กำกับความโปร่งใส การเคารพสิทธิ ความเป็นกลาง การรักษาความลับ และการสื่อสารสองทางกับผู้เกี่ยวข้อง

การนำโมเดลไปปฏิบัติ: ระบบจำแนกประเด็นเพื่อมองแนวโน้มด้านระบบ/TRACE ด้านบุคลากรและความเชื่อมั่น/TRUST และประเด็นผสม โดยผู้แจ้งไม่ต้องเลือกโมเดลเอง • ใช้กลยุทธ์ “สานต่อ–หยุดทำ–ปรับปรุง–ริเริ่ม” ร่วมกับการบริหารแบบบูรณาการและ 4M’s เพื่อให้การเปลี่ยนแปลงมีคน งบประมาณ วัสดุ/เทคโนโลยี และการจัดการรองรับ
